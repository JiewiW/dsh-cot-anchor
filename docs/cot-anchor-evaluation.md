# dsh-cot-anchor 插件功能评价

**评价对象**：dsh-cot-anchor v0.1.0（思考锚点：思维链监视与干预插件）
**评价维度**：提示词工程 · Harness 架构设计 · LLM 注意力与参数激活机制
**日期**：2026-10-02

---

## 1. 功能概述

插件针对弱模型在多工具、长推理链路中的两类失效：**遗忘已得结论**（重复推导）与**生成失控**（原地重复、语义空转、文本伪造工具调用）。功能由三条通路构成：

| 通路 | 挂载点 | 作用 |
|---|---|---|
| 结论锚点注入 | `tools/post-execute` | 每次工具执行后，从上一段思考中提取结论句注入上下文 |
| 生成中途软切断 | `agent/soft-cut` | 生成过程中检测失控，截断当前生成并注入纠偏锚点 |
| 静默学习闭环 | `session/event` | 采集真实思考样本 → LLM 归纳新特征 → 人工采纳后叠加生效 |

软切断内部按代价分级、按优先级触发：**伪造工具调用 → 字节级重复循环 → 语义空转 → 阶段转换**。越靠前者病理特征越确定、干预越激进；纯启发式触发则设多重退让条件。

---

## 2. 提示词工程角度

**优点**

- **注入文本即提示词，命令式且低歧义**。锚点统一采用"已确立结论，禁止重复推导，在此之上继续"的句式，中英双语，动词具体（Do not re-derive; build on them），模型无解释空间。
- **引用模型原话而非外部代拟**。锚点内容提取自模型自身的上一段思考。模型对自己刚刚生成的陈述具有天然的高承诺度，遵从性显著高于外部强加的结论。
- **提取保守，宁可不注入**。双层筛选（显式结论词句优先；无显式标记时才回退到内容信号句）、弱句过滤（疑问、条件、行动意图）、对冲词减分，保证注入内容均为"已落定"的判定——错误锚点的危害大于无锚点。
- **提示词防自我触发**。纠偏锚点刻意不复述被拦截的标签字面量，避免"检测→注入含触发词文本→再次检测"的自激振荡，这是生产事故后固化的设计。
- **学习层提示词契约严密**。归纳调用被四条硬约束封闭：只输出 JSON、仅 churn 检测器可接受字面量、仅 `churnMinHits` 一个可调阈值、禁止正则、裸常见词拉黑。输出形状与运行时消费能力严格对齐，从源头消除"采纳但永不生效"的死数据。

**不足**

- 高频注入存在**提醒疲劳**风险：锚点密度本身是设计目标，但长工具链中大量 notice 会稀释每条提示词的注意力权重。
- 注入文案为固定模板，不区分失效严重程度，提示强度无法自适应。

## 3. Harness 架构设计角度

**优点**

- **挂载点职责正交，各自独立可关**。采集（旁路观察者）、软切断（生成流干预）、事后注入（结果增强）三个介入深度不同的动作互不耦合，任一失效不扩散到其余通路。
- **观察者与被观察者隔离**。采集选 `session/event` 的 fire-and-forget 语义：提交后异步落盘，观察者异常被宿主吞掉，且能覆盖未调用工具的纯思考步；不选 `tools/post-execute` 是经过权衡的架构决策。
- **稳定性契约对齐宿主内部规范**。每条注入携带稳定唯一 id 并深度冻结，形状对齐官方 repeat-tool-reminder，规避持久收件箱的重复 id 硬冲突（首版 `message "undefined" is already pending` 事故的固化对策）。
- **中间件组合语义正确**。先 `await next()` 取得上下游判定，已有 cut 结论时直接放行，只在空地处增补——遵循链式责任而非覆盖式拦截。
- **从上下文侧切断失控，而非仅劝告**。重复检测产出 `trimTo`，失控尾部只保留一份写回会话，消除下一次请求整段回放→超长上下文→请求再失败的死循环；同段思考按指纹只注入一次，防止收件箱堆积。
- **完整的失败降级链**。LLM 提炼失败→规则提取器；设置写盘失败→仅当次生效；存储文件损坏→回退出厂默认。任何环节故障都不导致插件启动失败。
- **性能边界清晰**。内核每约 32 字咨询一次检测，全部检测窗口化（O(window) 而非 O(n²)），周期定位用倍增跳跃回溯，落盘防抖合并。

**不足**

- 软切断是破坏性操作，误切正常推理的代价不对称；当前靠"精确类激进、启发式保守 + 代码围栏退让 + 影子期"分级补偿，设计成熟但阈值仍依赖人工标定。
- 核心实现单文件近 3000 行，检测、采集、学习、路由集中，模块边界主要靠注释维持，维护成本偏高。

## 4. LLM 注意力机制与参数激活角度

**机理判断**

- **锚点对症的是注意力的位置衰减**。长上下文中存在中间信息遗忘（lost-in-the-middle），工具结果插入后，此前的结论被新 token 挤离注意力焦点。锚点在工具结果之后重述结论，把关键信息重新放到近因高权重位置——主动利用 recency 偏差补偿位置衰减。
- **注入时机选在注意力重分配点**。工具结果是新的强信号 token，模型下一轮推理的注意力在此刻重新分配；此时写入锚点，等于在高敏感位置施加外部偏置。
- **软切断重置阶段边界的有效上下文**。阶段转换处，生成易被前一阶段尾部的过渡短语惯性带偏。截断加锚点在推理轨迹上制造一个高显著度断点，使新阶段的生成条件于"已有结论"而非"刚才的动作意图"。
- **重复失控是自回归正反馈，外部劝告弱于输入侧干预**。重复一旦出现，相同 token 序列在采样中自我强化、概率分布坍缩，文本提示"别重复"通常无效。`trimTo` 直接改变下一次 forward 的可见输入，比在输出侧劝告更可靠——这是全插件机理上最正确的一处设计。
- **表层检测是对激活回路的行为计数**。churn 检测器统计重启短语的出现密度，实质是对"重新分析"生成回路被反复激活这一模式的外部观测，绕过语义理解、计算廉价。学习闭环用 LLM 语义归纳补其盲区，但语义层只产出普通字面量、编译权留在工程侧：语义能力用于发现，执行权限不外露，避免任意正则导致任意打断的失控激活。
- **影子期是未验证干预的观察缓冲**。新模式先只统计"本会触发几次"而不真切断，防止未经验证的外部偏置破坏正常推理路径。

**边界**

- 全部干预处于行为层面，不触及模型内部激活；字节级相等判据对微调字符的近义变体失效，短而密的转圈在长度门槛前可被放行。
- 阈值全局固定，除学习层单点调整外不随模型、任务类型自适应。

---

## 5. 总体评价

dsh-cot-anchor 是一个定位准确的**弱模型长链推理稳定性外挂**。其核心设计原则可概括为"**激进口径、分级兜底**"：对病理特征确定的失效（字节重复、伪造调用）零容忍即时切断，对启发式判断（语义空转、阶段转换）多重退让、先观察后生效。

最具价值的三处设计：从输入侧移除重复历史（而非劝告模型自律）、锚点引用模型原话并置于注意力重分配点、学习闭环中语义发现权与执行编译权分离。

主要改进方向：重复检测引入相似度判据以覆盖近义变体；拆分单文件实现、显式模块化；评估高频注入的注意力成本并考虑按严重度分级提示强度。
